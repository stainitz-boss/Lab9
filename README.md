# Домашнее задание к работе 9 (Вариант 6) : Равнобедренный треугольник.

## Условие задачи

> Напишите программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа.
> **Вариант 6:** Равнобедренный треугольник.
> Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.

## 1. Алгоритм и блок-схема

# Алгоритм

1. **Начало**
2. **Ввод данных:** символ `s` для отрисовки, высота `h`.
3. **Цикл (отрисовка строк):** от `i = 1` до `h` с шагом 1.
   - Вывод пробелов для центрирования (`h - i` штук).
   - Внутренний цикл (отрисовка символов в строке): от `j = 0` до `2 * i - 2`.
     - Если `j == 0` (левый край) **ИЛИ** `j == 2 * i - 2` (правый край) **ИЛИ** `i == h` (основание), вывести символ `s`.
     - Иначе вывести пробел (пустота внутри).
   - Переход на новую строку.
4. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    char s;
    int h, i, j;
    
    printf("Введите символ из которого будет строиться фигура:\n");
    scanf(" %c", &s);
    
    printf("Введите высоту:\n");
    scanf("%d", &h);
    
    printf("Равнобедренный треугольник:\n");
    
    for (i = 1; i <= h; i++) {
        for (j = 0; j < h - i; j++) {
            printf(" ");
        }
        
        for (j = 0; j < 2 * i - 1; j++) {
            if (j == 0 || j == 2 * i - 2 || i == h) {
                printf("%c", s);
            } else {
                printf(" ");
            }
        }
        printf("\n");
    }

    return 0;
}
```
